# BizGuide / bizguide.website

Static English site featuring only Registered Agents Inc. Upload all files in dist/ to a static host. No build dependencies.

## Activate referrals
Confirm affiliate approval and permission to promote, and list the actual public site URL in the AWIN profile. Edit dist/config.js: set affiliateApproved to true only after approval, and paste exact AWIN tagged URLs for formation, agent, domain and hosting. The site then displays the required affiliate identification and disclosure. No provider logo is used. Current pricing is intentionally omitted.

The domain is not connected by this project. Confirm intended hosting and current DNS before changing bizguide.website. This private review version is not a public visitor site.

## Publishing checklist
Verify current service information with the provider, add a real owner contact channel and adapt the privacy policy to final hosting and any future forms/analytics. Do not claim legal compliance or guaranteed formation outcomes. Read the full PPC terms before advertising: the supplied PPC summary and detailed ad-text provisions conflict. Do not use brand keywords or branded ad text without written clarification.

## GitHub Pages
Extract this ZIP. Upload the website files directly to the repository root (not the ZIP itself and not a containing folder). Preserve any existing CNAME if it already contains bizguide.website. In Settings > Pages use Deploy from a branch, main, / (root). Enable HTTPS when available. This upload replaces index.html and matching names: download a backup of the existing website first. The CNAME file declares the domain; it does not configure DNS.
